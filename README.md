# SQL Project Portfolio

Welcome to my SQL Project Portfolio! This repository showcases a collection of SQL-based projects I've worked on, demonstrating my skills across the full range of skills a data professional uses day to day — from basic filtering and aggregation through advanced window functions, query optimization, and database design. Every project is self-contained, with its own dataset context, SQL scripts, and a short write-up of the questions it answers.


## How to Use This Repository

1. Browse the Projects table above and open any project folder.
2. Each folder's README explains the dataset and the business questions the scripts answer.
3. SQL scripts are commented section-by-section and can be run directly against the described schema.
